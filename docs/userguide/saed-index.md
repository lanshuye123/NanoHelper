# SAED 指标化

本页处理「已经拍到一张选区电子衍射（SAED）图，如何标定斑点指数与带轴」的问题。它和 [电子衍射模拟](/docs/userguide/saed) 互为逆过程：

- 模拟：已知结构 + 带轴 → 斑点图；
- 指标化：已知斑点 R / 夹角 + 候选结构 → (hkl) 与带轴。

## 输入

### 测量模式

| 模式   | 输入                                    | 适用                        |
| ------ | --------------------------------------- | --------------------------- |
| R / Lλ | 两个斑点的 R（mm）与相机常数 Lλ（mm·Å） | 最常见；R 从底片/CCD 上量取 |
| 直接 d | 两个斑点的 d（Å）                       | 已用其他方式换算好 d        |

由 R 求 d：

$$
d=\frac{L\lambda}{R}
$$

相机常数可以用已知标样标定：

$$
L\lambda=R_{\text{std}}\cdot d_{\text{std}}
$$

页面提供「用 R·d 标定 Lλ」的小工具；也可以输入加速电压与相机长度，由电子波长自动计算 `Lλ = λL`。

### 角度

输入两个测量矢量之间的夹角（0–180°）。由于斑点可能有 ± 指数与 Friedel 对，程序同时接受 `θ` 与 `180° − θ`。

### 容差

- d 容差：相对误差，默认 3%；
- 角度容差：绝对误差，默认 3°；
- 最大指数：枚举 `|h|,|k|,|l| ≤ N`。

容差太严可能找不到候选；太松会给出很多伪候选。建议先用 3% / 3° 试，再逐步收紧。

## 算法

1. 在 `[-N, N]³` 内枚举所有非零 hkl；
2. 计算每个 hkl 的 d，保留与 d₁ / d₂ 在容差内的候选；
3. 对每一对候选计算倒易矢量夹角；
4. 保留角度在容差内的组合；
5. 带轴：

$$
[uvw]=\vec g_1\times\vec g_2
$$

6. 按最大公约数约化，并把第一个非零指数取正；
7. 若已加载空间群，用一般位置结构因子排除系统消光；
8. 按 `Δd₁ + Δd₂ + Δangle` 加权评分排序。

## 结果解读

- **首选候选**：带轴、两个 hkl、候选 d、夹角偏差与评分；
- **候选列表**：前 60 个组合，点击一行可在叠加图中查看；
- **叠加图**：橙色为测量的 R1/R2 方向，灰色为候选带轴的倒易点；
- **单斑候选**：只用一个 d 值匹配出的 hkl 列表。

带轴符号存在 ± 与等价方向；同一张图也可能对应多个带轴（尤其是高对称立方晶体）。应结合：

- 样品已知物相；
- 倾转系列中带轴的变化；
- 高分辨像的晶格条纹；
- 系统消光与动力学强度；

进一步确认。

::: warning 电子衍射的 180° 不确定性
电子衍射满足 Friedel 定律（运动学近似），`(hkl)` 与 `(-h-k-l)` 的强度相同。仅凭一张 SAED 图通常无法区分这两个方向；需要倾转或会聚束衍射。
:::

## 常见问题

**找不到候选？**

- Lλ 或 R 的单位不一致（mm vs cm vs px）；
- 角度量错（应量两个 R 矢量之间的夹角）；
- 晶胞参数错误或选错物相；
- 容差太严；先把 d 容差放到 5%、角度容差放到 5°。

**候选太多？**

- 收紧容差；
- 增大最大指数（有时低指数候选不够）；
- 加载正确的空间群，利用消光排除；
- 用第三个斑点的 R 与角度进一步筛选（当前版本只用两个斑点）。

**带轴与预期不符？**

检查 hkl 的符号约定与带轴约化；尝试把其中一个 hkl 取反，带轴会变号。立方晶系中 `[uvw]` 与 `[-u-v-w]` 是同一方向。

## 限制

- 只用两个斑点，不自动识别整张图的全部斑点；
- 运动学近似，不处理动力学强度、HOLZ、二次衍射；
- 不做全自动图像处理（斑点检测、圆心拟合）；
- 不处理相机畸变与底片扫描旋转；
- 消光检查依赖空间群数据库设置。
