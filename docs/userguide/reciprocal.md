# 倒易空间

本页从六个晶格参数出发，计算晶胞体积、倒易参数、晶面间距、晶面/晶向夹角、晶带轴与二维倒易面。

## 输入

| 参数 | 含义 | 单位 |
|---|---|---|
| a, b, c | 晶胞基矢长度 | Å |
| α, β, γ | 基矢夹角（b–c, a–c, a–b） | ° |
| 最大指数 | 枚举 `|h|,|k|,|l| ≤ N` | — |
| 点阵类型 | P/I/F/C/A/B/R，用于消光过滤 | — |
| 带轴 [u v w] | 二维倒易面的法向 | — |
| 显示半径 | 二维倒易面包含的最大 `|g|` | Å⁻¹ |

预设包括 Si、金刚石、NaCl、金红石、锐钛矿、ZnO、Mg、SrTiO₃、Al、Cu、Au、Fe、CsCl、MoS₂、GaAs。

## 晶格与倒易晶格

度规张量：

$$
G=\begin{pmatrix}
a^2 & ab\cos\gamma & ac\cos\beta\\
ab\cos\gamma & b^2 & bc\cos\alpha\\
ac\cos\beta & bc\cos\alpha & c^2
\end{pmatrix},
\qquad V=\sqrt{\det G}
$$

倒易度规 `G* = G⁻¹`。倒易基矢采用晶体学约定（**不含 2π**）：

$$
\vec a^* = \frac{\vec b\times\vec c}{V},\quad
\vec b^* = \frac{\vec c\times\vec a}{V},\quad
\vec c^* = \frac{\vec a\times\vec b}{V}
$$

页面同时给出 `a*, b*, c*, α*, β*, γ*`。

## 晶面间距

任意晶系：

$$
\frac{1}{d^2}=h^2a^{*2}+k^2b^{*2}+l^2c^{*2}
+2hk\,a^*b^*\cos\gamma^*
+2hl\,a^*c^*\cos\beta^*
+2kl\,b^*c^*\cos\alpha^*
$$

实现上直接用笛卡尔倒易矢量 `g = h a* + k b* + l c*` 的模长，避免手工判断晶系。

## 夹角

两晶面夹角（等于两倒易矢量夹角）：

$$
\cos\theta=\frac{h_1G^*h_2^\top}{\sqrt{h_1G^*h_1^\top}\sqrt{h_2G^*h_2^\top}}
$$

两晶向夹角：

$$
\cos\varphi=\frac{u_1Gu_2^\top}{\sqrt{u_1Gu_1^\top}\sqrt{u_2Gu_2^\top}}
$$

晶面与晶向夹角用 `90° − angle(g, r)` 计算，返回 0–90°。

::: tip 立方晶系的特例
在立方晶系中 `[hkl]` 正好垂直于 `(hkl)`；在非立方晶系中不一定。用倒易矢量计算永远安全。
:::

## 晶带轴

两晶面的交线即带轴：

$$
[u\,v\,w] = (h_1k_1l_1)\times(h_2k_2l_2)
$$

结果按最大公约数约化，并把第一个非零指数取正。晶带方程：

$$
hu+kv+lw=0
$$

页面会验证两个输入晶面是否满足该方程，并列出带内所有晶面（受最大指数与消光过滤限制）。

### 点阵消光

| 类型 | 条件 |
|---|---|
| P | 无 |
| I | h+k+l 偶数 |
| F | h,k,l 全奇或全偶 |
| C | h+k 偶数 |
| A | k+l 偶数 |
| B | h+l 偶数 |
| R | −h+k+l ≡ 0 (mod 3) |

::: warning 这只处理点阵消光
螺旋轴、滑移面导致的系统消光需要完整空间群与原子坐标，由 SAED/XRD 的结构因子自动处理。本页的过滤只是快速预览。
:::

## 二维倒易面

给定带轴 `[uvw]`，需要两个整数基矢 `b₁, b₂` 满足 `bᵢ·[uvw]=0`。程序：

1. 构造一组整数零空间基；
2. 用倒易度规做二维 Lagrange–Gauss 约化，得到最短、夹角接近 90° 的基；
3. 用 `g₁, g₂` 的模长与夹角建立二维笛卡尔坐标；
4. 以 `r(i,j)=i g₁+j g₂` 枚举斑点；
5. 用晶带方程自动处理含 0 的带轴（如 `[1 0 2]`）。

这等价于笔记中的「取倒数 → 最小整数比 → 截点 → 过原点 → 基矢」，但不需要手工设未知截距。

例：Si `[1 1 0]`，约化基矢：

- `b₁ = [0 0 1]`，`|g₁| = 1/a = 0.18413 Å⁻¹`；
- `b₂ = [1 -1 0]`，`|g₂| = √2/a = 0.26040 Å⁻¹`；
- 夹角 90°，det = 2。

## d 值表

- 枚举范围为 `[-N, N]`；
- 只保留**正半空间**代表：`h>0`，或 `h=0,k>0`，或 `h=k=0,l>0`，避免 Friedel 对重复；
- 按 d 降序排列；
- 点击一行会依次填入晶面 A / B；
- 最后一列给出 Cu Kα1 下的 2θ（若可观测）。

## 常见问题

**带轴输入后图为空？**

- 检查带轴是否全为 0；
- 显示半径太小或消光过滤过严；
- 该带轴下所有斑点都可能消光（例如某些特殊结构）。

**d 值与 PDF 卡片差一点？**

- 检查晶格参数与温度/固溶导致的偏移；
- 检查是否用了错误的晶系设置；
- 本页不包含仪器零点校正。

## 与 SAED 的联动

点击「用该带轴模拟 SAED」会把带轴写入 SAED 页。若当前使用预设结构，会同时把该预设设为 SAED/XRD 的当前结构；手动修改晶胞参数后，请在「晶体结构」页导入对应的 CIF 或重新选择预设，确保两边结构一致。
