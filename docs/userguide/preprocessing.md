# 预处理与逆处理

预处理不是「随便调一调」，而是由一串**可记录、可停用、可重算**的步骤组成。工具箱把它称为「步骤账本」。

## 步骤账本

- 每个步骤是一个对象：`{ type, enabled, params }`；
- 原始数据 `raw` 从不修改；
- 当前结果 `derived = applyPipeline(raw, enabledSteps)`；
- 停用/删除某一步，结果立即从原始数据重新计算；
- 上移/下移改变顺序；复制用于对比参数；
- 每一步都标注 **可逆 / 不可逆**。

| 步骤 | 作用 | 可逆 |
|---|---|---|
| 裁剪 crop | 保留 X 区间 | 否（丢失区间） |
| 重采样 resample | 变为均匀步长 | 否 |
| 平滑 smooth | 滑动平均 / Savitzky–Golay | 否（损失高频） |
| 扣背底 background | SNIP / 锚点线性 / 锚点多项式 | 否 |
| Kα2 剥离 kalpha2 | Rachinger | 否（改变峰形） |
| 归一化 normalize | 最大值 / 最小–最大 / 面积 | 否（但可由原始重算） |
| Jade 映射 jade-map | 仿射映射到 Jade 区间 | **是** |
| 自定义仿射 affine | 任意 `x'=ax+b, y'=cy+d` | **是** |

::: warning 不可逆 ≠ 不能反算
「不可逆」表示无法从处理后的曲线精确恢复原始曲线；但你可以随时在账本里停用它，从 `raw` 重算。导出配方时会保留全部参数。
:::

## 裁剪 crop

保留 `xMin ≤ x ≤ xMax` 的点。用于去掉低角空气散射、高角噪声或拼接边界。裁剪后至少需要 2 个点。

## 重采样 resample

把数据线性插值到固定步长。Kα2 剥离与部分寻峰算法假设等间距，建议先重采样。区间默认取当前数据的首尾；端点外使用最近值。

## 平滑 smooth

### 滑动平均

对窗口内取算术平均；窗口建议为奇数。边缘自动缩短窗口。

### Savitzky–Golay

在窗口内做低阶多项式最小二乘拟合，取中心点的拟合值。参数：

- **窗口**：奇数，建议 5–31；越大越平滑；
- **阶数**：2–4 常用；必须小于窗口。

实现上使用局部多项式设计矩阵的正规方程求解系数：

$$
c = e_0^\top (A^\top A)^{-1} A^\top
$$

边缘处自动缩短窗口并采用等权平均，避免端点发散；若对边缘敏感，可先裁剪。

::: tip 先扣背底还是先平滑？
一般顺序：裁剪 → 平滑（轻度）→ 扣背底 → Kα2 → 归一化。强平滑会让背底估计偏高，建议背底在轻度平滑后进行。
:::

## 扣背底 background

### SNIP

对正值数据做 LLS 变换后迭代削峰：

$$
z = \ln\!\left(\ln\!\left(\sqrt{y+1}+1\right)+1\right)
$$

每一步令 `z[i] = min(z[i], (z[i-p]+z[i+p])/2)`，迭代 `p = 1…iterations`，再逆变换。迭代次数越大，背底越平滑、越贴近数据低谷。

默认对包含负值的数据整体平移后再处理；返回的背底已抵消平移。

### 锚点线性 / 多项式

在曲线低谷处给出若干 `x, y` 锚点（每行一个，逗号或空格分隔），在锚点间线性插值或做多项式拟合，再逐点相减。

- 锚点至少 2 个；
- 多项式阶数 1–8，锚点数应大于阶数；
- 锚点不足时自动回退到 SNIP。

### 负值处理

默认把相减后的负值截断为 0。若保留负值，后续 Jade 映射会整体平移 Y，仍能满足 `Y>0`。

## Kα2 剥离 kalpha2

Rachinger 方法。对同一晶面，Kα2 的布拉格角满足：

$$
\sin\theta_2 = \frac{\lambda_2}{\lambda_1}\sin\theta_1
$$

在角度 `x` 处，Kα2 的贡献来自 Kα1 曲线在更低角度 `x'` 的值：

$$
I_1(x) = I_{\text{obs}}(x) - r\,I_1(x')
$$

其中 `r = I(Kα2)/I(Kα1)`，默认 0.5。实现按角度从低到高扫描，`I_1(x')` 取已修正曲线在 `x'` 的线性插值。结果截断负值。

参数使用当前靶材的 Kα1/Kα2 波长（Cu：1.54056 / 1.54439 Å）。若数据不是等间距，会先重采样。

::: warning Kα2 剥离会改变峰形
剥离后的峰宽不能直接与仪器标样比较；做 Scherrer 分析时，应使用相同处理流程处理标样。
:::

## 归一化 normalize

| 模式 | 公式 | 用途 |
|---|---|---|
| 最大值 | `y' = y / max(y) × target` | 叠图、相对强度 |
| 最小–最大 | `y' = (y−min)/(max−min) × target` | 压缩到固定区间 |
| 面积 | `y' = y / ∫y dx × target` | 定量比较峰面积 |

归一化只改变 Y 尺度，不改变峰位。它不可逆，但可以随时停用重算。

## Jade 坐标映射 jade-map

这是唯一为 Jade 设计的步骤。Jade 要求：

$$
0 \le x \le 140,\qquad y > 0
$$

映射模式：

| 模式 | X 变换 | Y 变换 | 适用 |
|---|---|---|---|
| 衍射数据 | 保持 2θ | 负值平移/裁剪 | XRD、SAED 2θ 谱 |
| 非衍射数据 | 线性映射到 `[0,100]` | 线性映射到 `[0.5,10000]` | Raman、FTIR、TGA |
| 安全区间 | 线性映射到 `[1,139]` | 同上 | 想避开边界时 |
| 自定义仿射 | `x'=ax+b` | `y'=cy+d` | 其他 |

通用仿射：

$$
x' = s_x x + t_x,\qquad y' = s_y y + t_y
$$

反算：

$$
x = \frac{x' - t_x}{s_x},\qquad y = \frac{y' - t_y}{s_y}
$$

系数以 10 位有效数字保存在配方中；页面同时显示「映射后范围」与警告。若数据含负值，Y 会整体平移；若 X 超出 0–140，会提示先裁剪或改用非衍射映射。

::: tip 为什么 Y 下限是 0.5 而不是 0
课程笔记要求非衍射数据 Y 归一化到 `[0,10000]`。Jade 要求 Y 严格大于 0，因此这里用 0.5 作为下限，几乎不影响相对强度。
:::

## 自定义仿射 affine

用于特殊坐标变换，例如：

- 把 2θ 转成 `1/d`（更推荐直接在 DIF 页做）；
- 把温度从 K 转成 °C；
- 给 X 加一个仪器零点偏移。

`affine` 与 `jade-map` 一样可逆，逆变换按系数反解。

## 逆处理

逆处理有三个入口：

1. **停用/删除步骤**：从 `raw` 重算，最彻底；
2. **曲线反算**：DIF → XY 页加载 `recipe.json`，把整条曲线映射回原始坐标；
3. **标量反算**：峰位 `x=(x'−t_x)/s_x`；峰宽乘以 `1/|s_x|`；峰面积乘以 `1/|s_x s_y|`。

导出配方时会写入：

- 原始数据的 X/Y 标签、单位、波长；
- 全部步骤及参数；
- `jade-map` 解析后的仿射系数；
- 原始数据与步骤的 FNV-1a 校验和。

::: warning 配方与数据要匹配
若配方来自另一个文件，DIF 页会在导出提示中保留警告。请确认点数、X 范围与波长一致。
:::

## 建议的处理顺序

```text
裁剪 → （轻度）平滑 → 扣背底 → Kα2 剥离 → 归一化 → Jade 映射
```

- 拟合前不要把峰形平滑过度；
- 归一化放在最后，避免影响背底判断；
- Jade 映射永远放在最后一步；
- 每一步都先看图表与兼容性检查，再继续。
