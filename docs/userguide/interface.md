# 界面与工作流

## 整体布局

```text
┌─────────────┬──────────────────────────────────────────────┐
│ 侧栏         │ 顶栏：面包屑 · 本地运行 · 文档 · 主题         │
│ 工作台       ├──────────────────────────────────────────────┤
│ 数据处理     │ 工具标题 / 操作按钮 / 文档入口                │
│ 晶体学计算   ├──────────┬─────────────────────┬─────────────┤
│ 资源         │ 配置面板  │ 主可视化 / 表格       │ 结果 / 检查器│
│             │ 可滚动    │ Canvas、表格         │ 可滚动       │
├─────────────┴──────────┴─────────────────────┴─────────────┤
│ 状态栏：本地运行 · 数据集摘要 · Jade 映射状态 · 版本         │
└──────────────────────────────────────────────────────────────┘
```

- **侧栏**：工具按「数据处理 / 晶体学计算」分组；底部可收起为图标栏。
- **顶栏**：面包屑、`本地运行` 指示、文档入口、深浅色切换。
- **状态栏**：当前数据集名称、点数、X/Y 范围、步骤数、Jade 映射是否启用。
- **三栏工作台**：配置在左，结果在中，检查器/提示在右。窗口宽度不足 1640 px 时，右栏自动移到主内容下方；小于 1100 px 时变为单栏。

## 工具页的统一结构

每个工具都有：

1. **标题与副标题**：说明这个工具解决什么问题；
2. **右上角操作**：导出、示例、文档；
3. **配置面板**：所有参数都带单位与校验；
4. **主可视化**：Canvas 图表或斑点图；
5. **结果面板**：表格、公式、警告；
6. **状态反馈**：成功/失败用顶部消息条，危险操作才用确认对话框。

## 图表交互

所有曲线图共用同一套 Canvas 交互：

| 操作 | 效果 |
|---|---|
| 滚轮 | 缩放 X 轴（以光标为中心） |
| `Alt` / `Ctrl` / `⌘` + 滚轮 | 缩放 Y 轴 |
| 按住左键拖拽 | 平移 X/Y |
| 双击 | 恢复自动范围 |
| 移动光标 | 十字线 + 数值提示（X、各曲线 Y） |
| 图例 | 多曲线时显示；曲线颜色与线型区分 |

图表下方会显示当前数据集的实际范围。导出的 PNG 使用固定 1600×900 画布，不包含鼠标提示。

::: warning 缩放不改变数据
缩放只改变视图。若需要截取区间，请使用「裁剪」步骤；否则导出的仍是完整数据。
:::

## 数据流

```text
文件 / 粘贴 / 示例
        │
        ▼
   Dataset（raw 原始数据，只读）
        │  步骤账本 steps[]
        ▼
   applyPipeline → derived（当前结果）
        │
        ├─► 曲线图（原始 vs 处理后）
        ├─► Jade 兼容性检查
        ├─► recipe.json（可复现配方）
        └─► 导出 .xy / CSV
```

- `raw` 永远不会被修改；任何步骤都可以停用/删除，结果从原始数据重新计算。
- 步骤顺序很重要：先裁剪再映射，与先映射再裁剪的结果不同。
- 右上角的 **撤销/重做** 记录步骤的增删、排序与启停；参数修改是即时生效的。
- 「保存工程」把 `raw + meta + steps` 写入一个 JSON，下次可以完整恢复。

## 主题

默认是深色「实验室」主题，适合长时间看衍射图与曲线。右上角的太阳/月亮按钮切换到浅色主题，选择写入 `localStorage`，下次打开仍然生效。

## 移动端

- 侧栏变为抽屉，顶栏左侧的菜单按钮打开；
- 三栏变为单栏，配置面板在图表上方；
- 表格横向滚动；
- 图表的触控缩放暂未实现，建议在桌面端处理数据。

## 快捷键与提示

| 快捷键 | 功能 |
|---|---|
| `Enter` | 提交数值输入框并重新计算 |
| `Esc` | 关闭对话框 / 取消输入 |
| 双击图表 | 恢复视图 |
| `Alt/⌘ + 滚轮` | 纵向缩放 |

数值输入框支持简单表达式：`1/3`、`2*1.5406`、`sqrt(2)`、`pi`。输入非法表达式时会红框提示并恢复原值。

## 文档入口

- 侧栏「资源」中的用户指南、实战手册、功能说明；
- 每个工具页右上角的 **文档** 按钮；
- 文档页右侧的「本页目录」可快速跳转；
- 文档中的内部链接在当前站点内跳转，不刷新页面。

## 状态与错误

| 位置 | 含义 |
|---|---|
| 顶栏绿色圆点 + 本地运行 | 没有后端请求 |
| 状态栏圆点灰色/绿色/黄色/红色 | 无数据 / 通过 / 警告 / 错误 |
| 顶部消息条 | 导入成功、导出成功、解析错误 |
| 面板内红色 `issue` | 阻止导出的错误，附修复建议 |
| 面板内黄色 `issue` | 不阻止导出，但可能影响拟合 |

遇到红色错误时先按提示修复；「Jade 导出」页与「导入与预处理」页使用同一套检查规则。
