# 界面与工作流

## 整体布局

```text
┌───────────────────────────────────────────────────────────────────────────┐
│ 品牌  首页 数据处理 衍射模拟 晶体几何 显微分析 文档中心 关于  [搜索] [本地] [主题] │
├──────────────┬────────────────────────────────────────────────────────────┤
│ 当前模块      │ 页面标题 · 副标题                       [操作] [文档]      │
│ 页面列表      ├──────────┬──────────────────────────┬─────────────────────┤
│ 可收起为图标栏 │ 配置面板  │ 主可视化 / 表格           │ 结果 / 检查器        │
├──────────────┴──────────┴──────────────────────────┴─────────────────────┤
│ 状态栏：本地运行 · 数据集摘要 · Jade 映射状态 · 版本                       │
└───────────────────────────────────────────────────────────────────────────┘
```

- **顶栏**：左侧是品牌，中间是模块标签页（首页 / 数据处理 / 衍射模拟 / 晶体几何 / 显微分析 / 文档中心 / 关于），右侧是全局搜索、本地运行指示、版本与深浅色切换。
- **侧栏**：显示**当前模块**的页面列表，顶部有模块图标、名称与一句话说明；底部可收起为图标栏。进入「文档中心」时，侧栏会按「用户指南 / 实战手册 / 功能说明 / 开发文档」分组列出全部文章，并提供搜索框。
- **内容区**：白色（深色模式下为深蓝）面板，工具页由标题区与三栏工作台组成。
- **状态栏**：当前数据集名称、点数、X/Y 范围、步骤数、Jade 映射是否启用。
- **三栏工作台**：配置在左，结果在中，检查器/提示在右。窗口宽度不足 1500 px 时，右栏自动移到主内容下方；小于 1180 px 时变为单栏。

## 模块与页面

| 顶栏模块 | 侧栏页面                                                       | 用途                       |
| -------- | -------------------------------------------------------------- | -------------------------- |
| 首页     | —                                                              | 模块入口、工作流与示例数据 |
| 数据处理 | 导入与预处理、Jade 导出、DIF → XY                              | 原始数据往返               |
| 衍射模拟 | 电子衍射模拟、XRD 模拟与分析                                   | 正演计算                   |
| 晶体几何 | 倒易空间、晶体结构、晶胞与密度、晶面与晶向、晶格精修、三维晶胞 | 晶格、结构与晶胞计算       |
| 显微分析 | 颗粒尺寸测量、SAED 指标化、电镜参数                            | SEM/TEM 图像与电子衍射     |
| 文档中心 | 四类文档分组                                                   | 指南、实战、参考、开发     |
| 关于     | 项目概览、数据来源、隐私、技术栈…                              | 项目信息与引用             |

顶栏标签用于**切换模块**，侧栏用于**切换模块内的页面**。所有模块共享同一个工作区状态：在「导入与预处理」载入的数据，可以在「XRD 模拟与分析」中作为实验谱叠加。

## 全局搜索

按 `Ctrl / ⌘ + K`，或点击顶栏右侧的搜索按钮，会打开快速跳转面板：

- 输入工具名、文档标题、模块名或关键词即可过滤；
- `↑` / `↓` 选择，`Enter` 打开，`Esc` 关闭；
- 结果同时包含工具页面与文档文章，并标注所属模块。

## 工具页的统一结构

每个工具都有：

1. **标题与副标题**：说明这个工具解决什么问题；
2. **右上角操作**：导出、示例、文档；
3. **配置面板**：所有参数都带单位与校验；
4. **主可视化**：Canvas 图表或斑点图；
5. **结果面板**：表格、公式、警告；
6. **状态反馈**：成功/失败用顶部消息条，危险操作才用确认对话框。

标题上方的 `模块 · 序号` 表示当前页面在模块中的位置，例如 `衍射模拟 · 01`。

## 图表交互

所有曲线图共用同一套 Canvas 交互：

| 操作                        | 效果                             |
| --------------------------- | -------------------------------- |
| 滚轮                        | 缩放 X 轴（以光标为中心）        |
| `Alt` / `Ctrl` / `⌘` + 滚轮 | 缩放 Y 轴                        |
| 按住左键拖拽                | 平移 X/Y                         |
| 双击                        | 恢复自动范围                     |
| 移动光标                    | 十字线 + 数值提示（X、各曲线 Y） |
| 图例                        | 多曲线时显示；曲线颜色与线型区分 |

图表下方会显示当前数据集的实际范围。导出的 PNG 使用固定 1600×900 画布，不包含鼠标提示。

::: warning 缩放不改变数据
缩放只改变视图。若需要截取区间，请使用「裁剪」步骤；否则导出的仍是完整数据。
:::

## 数据流

```text
文件 / 粘贴 / 示例
        │
        ▼
   Dataset（raw 原始数据，只读）
        │  步骤账本 steps[]
        ▼
   applyPipeline → derived（当前结果）
        │
        ├─► 曲线图（原始 vs 处理后）
        ├─► Jade 兼容性检查
        ├─► recipe.json（可复现配方）
        └─► 导出 .xy / CSV
```

- `raw` 永远不会被修改；任何步骤都可以停用/删除，结果从原始数据重新计算。
- 步骤顺序很重要：先裁剪再映射，与先映射再裁剪的结果不同。
- 右上角的 **撤销/重做** 记录步骤的增删、排序与启停；参数修改是即时生效的。
- 「保存工程」把 `raw + meta + steps` 写入一个 JSON，下次可以完整恢复。

## 自动保存与清空

每个工具页都会自动保存当前输入。切换页面或刷新后再次进入，页头会显示“已自动保存 HH:MM”，并恢复上次的参数；谱图、DIF、图像、粒径记录等较大的数据也会一并恢复。

页头右侧有两个动作：

- **恢复默认**：把本页输入恢复为初始值，但保留已导入的数据和当前晶体结构；适合作图前重新开始调参。
- **清空本页**：清空本页的输入、结果和自动保存记录；涉及数据的页面会同时移除本页拥有的数据。执行前会弹出确认。

约定：

- 普通页面清空时不会重置其他页面共用的晶体结构；共享结构在「晶体结构」页单独管理。
- 「清除本页」不会影响其他工具；只有「导入与预处理」页清空数据时，Jade 导出/DIF 等依赖当前数据的页面才会失去数据。
- 撤销/重做历史、弹窗开合状态、临时选中行不会保存。
- 自动保存失败时，页头会提示；此时请先导出需要的结果，或清空旧记录后重试。
- 三维晶胞查看器没有需要保存的输入，使用「重新载入」恢复视图。

## 主题

默认是**浅蓝—白**主题：深蓝色顶栏、浅蓝灰页面底色与白色内容面板。右上角的太阳/月亮按钮切换深色主题，选择写入 `localStorage`，下次打开仍然生效。两套主题共用同一组设计变量，图表与 Canvas 会随主题重新取色。

## 移动端

- 顶栏分为品牌行与模块标签行，标签可直接切换模块；
- 侧栏变为全高抽屉，由顶栏左侧的菜单按钮打开，右上角的关闭按钮或点击遮罩关闭；
- 三栏变为单栏，配置面板在图表上方；
- 表格横向滚动；
- 文档页的「目录」按钮在移动端打开文档抽屉；
- 图表的触控缩放暂未实现，建议在桌面端处理数据。

## 快捷键与提示

| 快捷键         | 功能                                |
| -------------- | ----------------------------------- |
| `Ctrl / ⌘ + K` | 打开全局搜索                        |
| `↑` / `↓`      | 在搜索结果中移动                    |
| `Enter`        | 打开选中的搜索结果 / 提交数值输入框 |
| `Esc`          | 关闭搜索或对话框                    |
| 双击图表       | 恢复视图                            |
| `Alt/⌘ + 滚轮` | 纵向缩放                            |

数值输入框支持简单表达式：`1/3`、`2*1.5406`、`sqrt(2)`、`pi`。输入非法表达式时会红框提示并恢复原值。

## 文档入口

- 顶栏「文档中心」模块，侧栏按分组列出全部文章，并支持搜索；
- 每个工具页右上角的 **文档** 按钮；
- 文档页右侧的「本页目录」可快速跳转；
- 文档中的内部链接在当前站点内跳转，不刷新页面。

## 状态与错误

| 位置                          | 含义                         |
| ----------------------------- | ---------------------------- |
| 顶栏绿色圆点 + 本地运行       | 没有后端请求                 |
| 状态栏圆点灰色/绿色/黄色/红色 | 无数据 / 通过 / 警告 / 错误  |
| 顶部消息条                    | 导入成功、导出成功、解析错误 |
| 面板内红色 `issue`            | 阻止导出的错误，附修复建议   |
| 面板内黄色 `issue`            | 不阻止导出，但可能影响拟合   |

遇到红色错误时先按提示修复；「Jade 导出」页与「导入与预处理」页使用同一套检查规则。
