# Jade 导出

本页把当前处理结果写成 **MDI Jade 可直接读取的两列 XY**，并生成可复现的配方。

## Jade 的硬约束

课程笔记与实测一致：

- 横坐标（2θ 或归一化 X）必须在 **0–140** 之间；
- 纵坐标必须始终 **大于 0**；
- X 单调递增；
- 两列、空白分隔、ASCII 文本；
- Windows 版 Jade 对 CRLF 更稳定。

Jade 对表头与注释的兼容性因版本而异，因此默认**不写表头**。

## 坐标映射

在「导入与预处理」中添加 `jade-map` 步骤后，本页会显示解析出的系数、映射后范围与逆变换。

| 模式 | X | Y |
|---|---|---|
| 衍射数据 | 保持 2θ；超出范围会报错 | 负值平移；默认不缩放 |
| 非衍射数据 | 线性映射到 `[0,100]` | 线性映射到 `[0.5,10000]` |
| 安全区间 | 线性映射到 `[1,139]` | 同上 |
| 自定义仿射 | `x'=ax+b` | `y'=cy+d` |

非衍射模式的 Y 下限取 0.5 而不是 0，是为了满足 Jade 的严格正性；相对强度几乎不受影响。

::: tip 保留原始坐标
导出 `.xy` 后，Jade 里看到的峰位是映射后的坐标。拟合完成后，在 DIF → XY 页加载 `recipe.json`，即可把峰位、峰宽和强度反算回 Raman/IR 的原始坐标。
:::

## 兼容性检查

| 检查 | 级别 | 处理 |
|---|---|---|
| X 超出 `[0,140]` | 错误 | 裁剪，或改用非衍射映射 |
| Y ≤ 0 | 错误 | 平移 Y、扣背底或归一化 |
| NaN / Infinity | 错误 | 删除或插值 |
| X 非单调 | 错误 | 排序/重新导入 |
| 重复 X | 警告 | 可容忍；建议去重 |
| 步长不均匀 | 警告 | 可容忍；必要时重采样 |
| 步长过小 | 警告 | 抽稀 |
| 点数 > 200000 | 警告 | 抽稀或分段 |

存在任一错误时，**导出按钮会被禁用**，并给出修复方向。

## 导出选项

| 选项 | 默认 | 说明 |
|---|---|---|
| X 小数位 | 6 | 反算误差约 1e-6 |
| Y 小数位 | 4 | 对计数足够 |
| 换行 | CRLF | Windows / Jade 推荐 |
| 注释表头 | 关闭 | 打开后以 `#` 开头；部分 Jade 版本会忽略 |
| 文件名 | `{数据名}_{YYYYMMDD_HHmm}.xy` | 会过滤非法字符 |

导出的每一行：

```text
0.000000 211.7699
0.026316 217.4856
0.052632 222.6806
```

## 配方 JSON

配方包含：

- `schema: crystaltoolbox/recipe@1`；
- 原始元数据（X/Y 标签、单位、波长、靶材、点数、范围）；
- 全部启用的步骤及其参数；
- `jade-map` 解析后的 10 位仿射系数；
- `checksum`（原始数据的 FNV-1a 哈希）；
- 应用名与版本。

示例（节选）：

```json
{
  "schema": "crystaltoolbox/recipe@1",
  "name": "Raman · 锐钛矿",
  "mapping": {
    "xScale": 0.05263157895,
    "xOffset": -5.263157895,
    "yScale": 10.6087,
    "yOffset": -1429.7585
  },
  "steps": [
    { "type": "smooth", "params": { "method": "sg", "window": 11, "order": 3 } },
    { "type": "jade-map", "params": { "mode": "nonDiffraction" } }
  ],
  "checksum": "fnv1a:…"
}
```

配方不包含完整数据点；它描述「如何变换」。因此必须与原始数据一起保存。

## 在 Jade 中导入

1. 打开 Jade → **File → Read**；
2. 文件类型选 `*.xy` 或 `All files`；
3. 选择导出的文件；
4. 确认横坐标为 2θ（或归一化 X）、纵坐标为强度；
5. 做背底（BE）、寻峰（Fit）、拟合；
6. **File → Save → DIF** 导出拟合结果。

::: warning 不要用 Jade 重新归一化
如果你在 Jade 里再做一次归一化，峰位不变，但峰面积会变。回 Origin 时请使用原始配方反算，而不是在 Jade 里手动改坐标。
:::

## 常见问题

### Jade 打不开或只显示一条直线

- 检查文件是否为空、X 是否在 0–140；
- 检查是否误写了表头；
- 用文本编辑器确认两列之间是空格且没有中文；
- 尝试把换行改为 CRLF。

### 峰位看起来不对

- 非衍射数据在 Jade 中显示的是映射后的 X；这是预期的；
- 用 `recipe.json` 反算后再与 PDF 卡片比较；
- 检查映射模式是否选错（例如把 XRD 当成了非衍射数据）。

### 配方与数据不匹配

- 配方记录的是生成它时的数据范围与校验和；
- 换了一份数据后，映射系数通常不再适用；
- 在 DIF 页加载配方时注意提示，必要时重新生成映射。
