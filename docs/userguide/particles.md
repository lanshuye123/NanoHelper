# 颗粒尺寸测量

本页是一个类 **NanoMeasure** 的 SEM/TEM 粒径工作流：

1. 在电镜图上画一条线覆盖标尺，输入标尺真实长度；
2. 逐颗拖拽画线测量，或用阈值 + 连通域自动识别；
3. 实时统计平均值、标准差、D10/D50/D90、分布直方图与高斯/对数正态拟合；
4. 导出 CSV、NanoMeasure 风格 TXT、标注 PNG、分布 PNG 与工程 JSON。

全部计算在浏览器本地完成，图像不会上传。

## 1. 标尺标定

在左侧「① 标尺标定」中点击「画标尺」，然后在图像上拖拽一条线覆盖 SEM 自带的标尺。松开后会显示像素长度，输入标尺的真实长度与单位（nm / µm / mm），点击「应用标尺」。

标定结果：

$$
\text{nm/px}=\frac{\text{标尺真实长度 (nm)}}{\text{标尺线像素长度}}
$$

注意：

- 标尺线越短，相对误差越大；
- 尽量沿着标尺的水平/垂直方向画；
- 标尺线覆盖整条标尺，而不是其中一小段；
- 更改标尺后，已有测量会按像素长度重新换算；更换图像会清空当前测量。

## 2. 手动画线测量

完成标定后，切换到「画线测量」。在图像上跨过一颗颗粒拖拽一条线，松开即记录一条 **Feret 直径**（沿测量方向的两点距离）。每次测量会：

- 在图上画出测量线与序号；
- 在右侧「测量记录」中新增一行；
- 立即更新统计卡片与直方图。

点击测量线或表格行可以选中；右侧表格的删除按钮可删除误测。滚轮缩放，`Shift + 拖拽` 平移，双击「适应窗口」。

## 3. 全屏测量

标定完成后，点击测量卡片或图像工具栏里的「全屏」/「全屏测量」，进入全屏工作区。全屏只保留标尺状态、图像、缩放、画线/平移与撤销/清空，方便逐颗标记。

- 按 `Esc` 或点击「退出全屏」返回；
- 进入全屏后会自动把图像适配到可用区域；
- 全屏不会改变已有测量与标尺。

## 4. 自动识别（可选）

「③ 自动识别」使用简单的两相分割：

1. 灰度化（`0.299R + 0.587G + 0.114B`）；
2. 自动 Otsu 阈值或手动阈值；
3. 按「暗颗粒/亮颗粒」生成前景掩膜；
4. 8 连通域标记；
5. 按面积、圆度过滤；
6. 面积等效圆直径：

$$
d_{\text{eq}}=2\sqrt{\frac{A}{\pi}}
$$

识别结果先以绿色圆圈叠加在图上，点击「采纳」后才加入测量表。自动识别适合高对比、分散的颗粒；**粘连颗粒会被合并**，此时请用手动画线。

::: tip 手动画线与自动识别的口径不同
手动画线得到 Feret 直径；自动识别得到面积等效圆直径。两者可以混用，但论文中应说明测量方法与统计口径。CSV 的 `method` 列会保留每条记录的来源。
:::

## 5. 统计

设粒径为 `d_i`，样本数 `n`：

$$
\bar d=\frac{1}{n}\sum_i d_i,\qquad
s=\sqrt{\frac{1}{n-1}\sum_i(d_i-\bar d)^2}
$$

分位数用线性插值；D10、D50、D90 分别是 10%、50%、90% 分位数。跨度：

$$
\mathrm{Span}=\frac{D_{90}-D_{10}}{D_{50}}
$$

变异系数 `CV = s / d̄`。偏度与峰度用总体矩定义（峰度为超额峰度）。

直方图默认 10 组，组距用「1 / 2 / 2.5 / 5 × 10ⁿ」的 nice step；分组采用 NanoMeasure 的上偏约定：**左闭右开**，2.5 落在 2.5–3.0 组，末组含上限。

拟合：

- 高斯：均值与样本标准差；
- 对数正态：对 `ln d` 做最大似然，给出 `μ`、`σ`、中位数、均值、众数。

## 6. 导出

| 文件      | 内容                                                 |
| --------- | ---------------------------------------------------- |
| 测量 CSV  | 每条测量的尺寸、像素长度、面积、圆度、端点坐标、方法 |
| 分组 CSV  | 组下限/上限、计数、频率，以及拟合参数注释            |
| TXT 报告  | NanoMeasure 风格的「基本报告 + 统计报告 + 汇总」     |
| 标注 PNG  | 原图 + 标尺线 + 测量线/序号                          |
| 分布 PNG  | 直方图 + 拟合曲线                                    |
| 工程 JSON | 标定、统计、直方图、测量数组（不含图像像素）         |

CSV 带 UTF-8 BOM，可直接用 Excel / Origin 打开。TXT 的「基本报告」可直接复制到 Origin，或用于 Frequency Count。

## 常见问题

**图像打不开？**

浏览器原生支持 PNG/JPEG/BMP/WebP；TIFF 通常不支持。可先用 ImageJ / DigitalMicrograph 导出为 PNG。

**测出来是 0 或 NaN？**

尚未完成标定，或标尺线长度为 0。请重新画标尺并应用。

**自动识别结果太多/太少？**

调整阈值、最小面积与最大圆度；暗颗粒与亮颗粒要选对；必要时先裁剪图像。

**统计结果与 NanoMeasure 不完全一致？**

NanoMeasure 的具体分组规则、圆度定义与拟合实现未公开；本页采用明确的左闭右开分组与面积等效圆定义，并在 CSV 中保留原始像素数据以便复核。

## 限制

- 自动识别不做分水岭分割，粘连颗粒会合并；
- 不做亚像素边缘拟合、不做形状因子分类；
- 不测量孔隙率、长宽比、取向；
- 图像与测量记录会自动保存；换设备前建议导出 CSV/TXT 与标注 PNG 备份；
- 测量精度受图像分辨率、标尺精度与人为选点影响。
