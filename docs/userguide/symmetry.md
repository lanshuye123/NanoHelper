# 对称性、消光与手性

本页把空间群的对称操作、等效位置、系统消光与手性放在同一个查询界面里，适合在指标化、结构描述和空间群判断时快速核对。

## 输入

- **空间群**：按编号或符号筛选 230 个空间群。
- **坐标 (x, y, z)**：输入分数坐标，查看该位置的等效位置数、位置对称性阶数与具体坐标。
- **筛选**：按 hkl 过滤消光表；可展开全部一般位置。

## 输出

- 空间群摘要：晶系、点群、点阵类型、一般位置数、手性判断。
- 一般位置列表（Seitz 记号）。
- 指定坐标的等效位置、多重度与位置对称性阶数，并标明一般位置/特殊位置。
- 反射条件：h00、0k0、00l 与点阵消光。
- 系统消光表：h、k、l ≤ 8 的允许/消光判定与 |F_gen|。

## 手性

若空间群只含旋转轴、螺旋轴等正当操作，不含反演、镜面、旋转反演或滑移面，则属于手性空间群。手性空间群与其镜像空间群在衍射强度上可能存在差异；实际判断手性还需要结合消光规律、会聚束电子衍射或 anomalous scattering。

本页的判断依据是全部对称操作旋转部分的行列式：出现行列式为 −1 的操作即判为非手性。

## 系统消光

在一般位置放置一个原子，对全部对称操作求结构因子：

$$
F_{gen}(hkl)=\sum_j e^{2\pi i(hx_j+ky_j+lz_j)}
$$

当 |F_gen| ≈ 0 时，该反射与原子种类无关地系统消光。点阵消光（P/I/F/C/A/B/R）与螺旋轴、滑移面造成的附加条件都会体现在这个求和中。

## 示例

- **P -1**：含反演中心，非手性；一般位置数 2；原点为特殊位置，位置对称性阶数为 2。
- **P 1 21 1**：只含 21 螺旋轴，手性；一般位置数 2。
- **Fd-3m**：面心立方，含 d 滑移面与反演相关操作，非手性；一般位置数为 192。

## 关于 Wyckoff 字母

本页给出等效位置数与位置对称性阶数，但不猜测 Wyckoff 字母。字母需要对照国际晶体学表或结构文件中的标注确认，避免把“多重度相同”误认为“字母相同”。

## 边界

- 消光表按 h、k、l ≤ 8 枚举，未列出的高指数反射可用同一规则外推；
- 只处理理想空间群，不考虑超结构、调制结构与无序；
- 手性判断是群论层面的判断，不等于样品一定具有可观测的手性信号。
