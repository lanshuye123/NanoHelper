# 数据导入

「导入与预处理」是数据进入工具箱的第一站。导入器全部在浏览器本地运行，支持拖拽、文件选择和文本粘贴。

## 支持格式

| 格式 | 扩展名 | 解析方式 | 说明 |
|---|---|---|---|
| 通用文本表 | `.csv` `.tsv` `.txt` `.xy` `.dat` `.asc` | 自动嗅探分隔符与表头 | 最常用；两列即 X + 强度 |
| Jade DIF | `.dif` | 专用多块解析器 | 导入时取 Raw 曲线；完整功能在「DIF → XY」页 |
| PANalytical XRDML | `.xrdml` | XML 标签解析 | 支持多 scan、positions 或 start/end/step |
| Bruker UXD | `.uxd` | 通用文本表 | 两列 2θ/强度 |
| 剪贴板文本 | — | 通用文本表 | 从 Excel/Origin 直接粘贴 |

::: tip 不支持二进制原始文件
`.brml`、`.raw`、`.mdi`、`.cif` 需要各自的解码器。CIF 请到「晶体结构」页导入；二进制厂商格式建议先在仪器软件里导出为文本。
:::

## 解析规则

通用文本解析器会：

1. 把 CRLF/CR 统一成 LF，去掉 BOM；
2. 跳过以 `#`、`;`、`//` 开头的注释行；
3. 自动判断分隔符：制表符 → 分号 → 逗号 → 空白；
4. 若首行不是数字，视为列名；
5. 保留数值列，忽略全部为非数值的列；
6. 若 X 不单调递增，按 X 排序并给出提示；
7. 分号分隔且形如 `10,5` 的单元格按小数逗号处理。

### 编码

先按 UTF-8 严格解码；失败则尝试 GBK（常见于中文 Windows 仪器软件）；再失败则用 UTF-8 容错并提示。若中文标题乱码，请在仪器软件中另存为 UTF-8。

### 表头与列映射

- 两列文件直接使用第 1、2 列；
- 多于两列时，左侧会出现 **列映射** 面板，可分别选择 X 列与 Y 列；
- 切换列会基于原文件重建数据集，**已添加的步骤会清空**（避免用错坐标继续处理）；
- 列名会显示在 X/Y 选择器中，来源是首行或注释行。

### 元数据推断

| 线索 | X 标签 | 单位 |
|---|---|---|
| 表头含 `2theta` / `2θ` | 2θ | ° |
| 表头含 `raman` | Raman shift | cm⁻¹ |
| 表头含 `wavenumber` / `IR` | Wavenumber | cm⁻¹ |
| 表头含 `temperature` / `temp` | Temperature | °C |
| 无表头，但 0 ≤ X ≤ 140 | 2θ | ° |
| 其他 | X | — |

Y 标签同理推断为 Counts、Transmittance、Mass 或 Intensity。推断结果只影响显示与配方记录，可在后续页面直接使用；目前不提供单独的元数据编辑器。

## 示例数据

| 示例 | 特点 | 建议练习 |
|---|---|---|
| XRD · 锐钛矿 TiO₂ | 20–80°，含 Kα2 与泊松噪声 | 峰位、Kα2 剥离、Jade 导出 |
| Raman · 锐钛矿 | 100–2000 cm⁻¹，五个特征峰 | 非衍射数据映射与逆处理 |
| TGA · 两段失重 | 30–800 °C，Y 有基线 | 归一化、平滑、坐标映射 |
| FTIR · 氧化物 | 400–4000 cm⁻¹ 透过率 | 反向 X 轴/峰识别 |
| Jade DIF · DEMO06 | 真实六块拟合结果 | DIF → XY 多列导出 |

## DIF 导入与 DIF → XY 的区别

- 从「导入与预处理」导入 `.dif`：只取 **Raw Pattern** 作为当前数据集，可以继续做平滑、映射、导出；
- 从「DIF → XY」导入：保留全部块（Background、Fitted Profile n、Overall），用于 Origin 多列导出与反算。

如果你要做的是「把拟合结果画图」，请直接用 DIF → XY 页。

## 导入报告与警告

导入完成后会显示：

- 文件格式、点数、编码；
- 被跳过的行数；
- 列名与自动推断结果；
- 解析警告（如长度不一致、非数值单元格）。

常见警告及处理：

| 警告 | 处理 |
|---|---|
| X 轴不是单调递增，已排序 | 确认没有把两段扫描拼反 |
| 存在重复 X 值 | Jade 可容忍；导出前可去重 |
| 非数值内容已忽略 | 检查是否混入了单位行或页脚 |
| positions/counts 长度不一致 | XRDML 某一段损坏，检查原始文件 |
