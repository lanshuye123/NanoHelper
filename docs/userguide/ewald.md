# 艾瓦德球与劳厄带

本页把倒易点阵、艾瓦德球与带轴电子衍射放在同一个几何图里，用来回答三个问题：

1. 为什么电子衍射可以同时看到许多斑点，而 X 射线粉末衍射需要大量晶粒取向？
2. 哪些倒易点落在零阶劳厄带（ZOLZ），哪些落在高阶劳厄带（HOLZ）？
3. 样品厚度和入射波长怎样改变“斑点是否与球相截”的判断？

## 输入

- **晶体结构**：使用「晶体结构」页当前选中的结构，或直接在结构选择器中切换预设。
- **入射束**：电子或 X 射线。电子用加速电压换算波长；X 射线可选靶材或直接输入波长。
- **带轴 [u v w]**：电子束沿该方向入射；倒易面垂直于该方向。
- **样品厚度**：用于把倒易点拉长成倒易杆。厚度越小，倒易杆越长，越容易与球相截。
- **最大 |g|**：控制枚举范围，单位为 Å⁻¹。

## 输出

- 径向截面图：横轴是倒易面内的径向距离 r，纵轴是沿带轴法向的 z。
- ZOLZ / HOLZ 标记：ZOLZ 对应 h·u + k·v + l·w = 0；HOLZ N 对应 h·u + k·v + l·w = N。
- 每个倒易点的 d、|g|、劳厄带 N、激发误差 s 与是否相截。
- 电子与 Cu Kα1 的曲率对比：同一 |g| 下，X 射线的 s 远大于电子衍射。

## 几何关系

艾瓦德球半径按晶体学约定取

$$
k=\frac{1}{\lambda}
$$

在径向截面中，球面满足

$$
r^2+(z+k)^2=k^2
$$

因此倒易点到球面的有符号距离为

$$
s=\frac{x^2+y^2+z^2+2kz}{2k}
$$

当样品厚度为 t 时，倒易杆半长为 1/(2t)；|s| 小于该值时，本页把该点标为“相截”。这是一个运动学几何判据，不包含动力学散射、倾转与 HOLZ 线细节。

## 怎么读图

- 先看 ZOLZ 是否形成规则的二维网格；这是带轴电子衍射的主斑点。
- 再看 HOLZ 点：它们通常较弱，但对确定带轴与晶体对称性有帮助。
- 增大厚度，倒易杆变短，相截的点会减少；减小厚度，斑点更容易同时出现。
- 把入射束从电子切换为 X 射线，注意 k 与曲率的变化：X 射线的球半径只有约 0.65 Å⁻¹，远小于电子的约 40 Å⁻¹。

## 示例

选择 Si，带轴 [1 1 0]，电子 200 kV，厚度 50 nm，最大 |g| = 1.2 Å⁻¹：

- ZOLZ 中可见 111、002、220 等允许反射；
- 111 的 d ≈ 3.135 Å，002 在 Si 中系统消光；
- HOLZ 点出现在 z = ±1/|R₁₁₀| 的附近。

## 边界

- 只做几何计算，不模拟动力学衍射强度、吸收、样品倾斜和 HOLZ 线；
- 倒易杆模型是简化模型，厚度的定义是均匀薄片；
- 显示范围受最大 |g| 与枚举上限影响，极高角反射可能未列出。
