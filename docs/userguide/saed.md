# 电子衍射模拟

本页按运动学近似模拟**带轴电子衍射**（ZOLZ）：给定晶体结构与带轴，计算斑点位置、指数与相对强度。

## 输入

| 参数 | 说明 |
|---|---|
| 晶体结构 | 预设或 CIF；与 XRD/结构页共享 |
| 带轴 [u v w] | 电子束入射方向（ZOLZ） |
| 加速电压 | 100/200/300 kV 等；决定电子波长 |
| 相机长度 L | mm；决定斑点半径 |
| 最大 \|g\| | 参与计算的倒易空间半径 |
| 斑点大小 | √I / 线性 / 等大 |
| 隐藏消光 | 是否隐藏 \|F\|≈0 的斑点 |

## 电子波长

相对论修正：

$$
\lambda=\frac{h}{\sqrt{2m_e eV\left(1+\frac{eV}{2m_ec^2}\right)}}
$$

| 电压 | 波长 |
|---|---|
| 100 kV | 0.03701 Å |
| 200 kV | 0.02508 Å |
| 300 kV | 0.01969 Å |

## 斑点位置

倒易矢量 `g = h a* + k b* + l c*`。屏幕半径：

$$
R = L\lambda\,|g| = \frac{L\lambda}{d}
$$

其中 `Lλ` 称为相机常数（mm·Å）。页面显示：

- `|g|` 与 `d = 1/|g|`；
- `R`（mm）；
- 相对强度 `I ∝ |F|²`；
- 二维基矢与夹角。

## 强度

$$
F(hkl)=\sum_j f_j(s)\,occ_j\,e^{-B_js^2}\,e^{2\pi i(hx_j+ky_j+lz_j)},\qquad
I\propto|F|^2
$$

- `s = sinθ/λ = |g|/2`；
- 散射因子为 Waasmaier–Kirfel 五高斯参数化；
- 系统消光由完整晶胞的原子求和自动处理（结果为数值上的零）；
- 未考虑动力学散射、样品厚度、HOLZ、吸收与探测器响应。

::: warning 运动学近似
电子与物质相互作用很强，实际 SAED 常出现动力学效应（强度反常、禁戒反射出现）。本工具适合教学与几何标定，不用于定量强度分析。
:::

## 二维基矢

与倒易空间页一致：由带轴求整数零空间基，再做二维 Gauss 约化。页面显示 `b₁, b₂, |g₁|, |g₂|, 夹角`。

## 标定

### 已知 R 与 d

$$
L\lambda = R\cdot d
$$

在「显示与标定」中输入实测 R（mm）与已知 d（Å），即可得到相机常数与对应的相机长度。

### 已知 Lλ，求未知 d

$$
d=\frac{L\lambda}{R}
$$

页面会实时显示当前 R 对应的 d。

### 多晶环

本页针对单晶带轴斑点。多晶环请用 XRD 或专门的环标定工具；若要用本页，可把每个环看作一个 d 值，逐一反推。

## 导出

- **PNG**：1600×1600 的斑点图，含比例尺与指数；
- **CSV**：`h,k,l,d_A,g_invA,I_rel,R_mm,x_mm,y_mm`。

CSV 可直接在 Excel/Origin 中筛选强斑点，或作为标定记录归档。

## 示例：Si [110]，200 kV，L = 800 mm

- `λ = 0.025079 Å`；
- `Lλ = 20.063 mm·Å`；
- `(004)`：`g = 4/5.431 = 0.7365 Å⁻¹`，`R = 14.78 mm`；
- `(1 -1 1)`：`g = 0.3189 Å⁻¹`，`R = 6.40 mm`；
- `(002)` 在金刚石结构中系统消光，不应出现。

## 常见问题

**斑点太少**

- 增大「最大 \|g\|」；
- 检查带轴是否输入错误；
- 确认结构是否包含原子（无原子时按等强度显示）；
- 某些带轴确实只有少量允许反射。

**中心斑点偏移**

- 本工具以 (000) 为几何中心；实验图可能因束流偏转而偏移，标定时应以透射斑为原点测量 R。

**强度与实验不符**

- 运动学近似 + 无厚度/动力学效应；
- 实验图的亮度还受曝光、探测器与后处理影响。
