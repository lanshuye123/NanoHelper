# 常见问题

## 导入与解析

### 导入后页面空白 / 没有数据

1. 确认文件至少有 2 列数值；
2. 用文本编辑器查看前几行，排除单位行、页脚、合并单元格；
3. 尝试「粘贴文本」入口，排除编码问题；
4. 若是 `.xrdml`，确认包含 `<counts>` 标签；
5. 若使用 `file://` 打开构建产物，改用 `npx serve dist`。

### 中文标题乱码

文件很可能是 GBK。浏览器会先按 UTF-8 严格解码，失败后回退 GBK；若仍乱码，请在仪器软件中另存为 UTF-8，或把标题行删除（不影响数值）。

### 多列文件选错了列

在左侧「列映射」中重新选择 X/Y，然后点击 **应用列映射**。注意：这会基于原文件重建数据集，已添加的步骤会清空。

### `.raw` / `.brml` / `.mdi` 打不开

这些是二进制或厂商私有格式，本工具不解析。请先在仪器软件中导出为 `.xy` / `.csv` / `.xrdml`，或在 Jade 中另存为文本。

## Jade 相关

### X 超出 [0,140]

- XRD 数据：裁剪到 0–140；
- Raman/IR/TGA：添加「Jade 坐标映射」，选择非衍射模式；
- 若只是想看全谱，先不要导出，映射只影响导出与 Jade 检查。

### Y ≤ 0

- 扣背底后出现负值：打开「负值截断」或加一个 Y 平移；
- 归一化后仍有负值：改用最大值归一化；
- 映射步骤会整体平移 Y，保证 Jade 中为正。

### Jade 打不开导出的 `.xy`

- 确认没有写表头（默认关闭）；
- 确认使用 CRLF；
- 确认 X 在 0–140、Y > 0；
- 用文本编辑器确认每行恰好两个数；
- 尝试把扩展名改为 `.txt` 再导入。

### 峰位在 Jade 中看起来不对

非衍射数据在 Jade 中显示的是映射后的 X（0–100），不是原始 Raman shift。拟合完成后，在 DIF 页加载 `recipe.json` 反算即可。

## DIF 与反算

### DIF 解析失败

- 确认是 Jade 导出的 `.dif`，不是 `.mdi`；
- 确认第一行之后存在参数行（包含 start、step、anode、wavelength、end、npoints）；
- 检查文件是否被 Excel 改写过（可能丢失空格或科学计数法）；
- 保留原文件，便于定位。

### 反算后峰位仍然不对

- 配方是否来自同一份原始数据？（看 `checksum` 与点数）
- 映射模式是否一致？
- 是否在 Jade 中又做了一次坐标变换/归一化？
- 是否把 1/d 轴与配方同时使用？

### Rp 很高

`Rp = Σ|Raw−Overall|/Σ|Raw|`，不含权重。若差值曲线在强峰处明显偏离，说明拟合本身不好；若只在低角/高角偏离，可能是背底或峰型选择不当。

## 晶体学计算

### SAED 斑点太少

- 增大「最大 |g|」；
- 检查带轴；
- 某些带轴确实只有少量允许反射；
- 若结构没有原子，斑点按等强度显示，但仍受几何限制。

### SAED 强度与实验差很多

本工具是运动学近似，未考虑动力学散射、样品厚度、HOLZ、探测器响应。请只用它做几何标定与指数标注。

### XRD 强度与 PDF 卡片不同

- 本工具只含结构因子、多重度与 LP；
- 不含择优取向、吸收、仪器几何、单色器偏振；
- 温度因子只用了各向同性 B；
- PDF 卡片的相对强度也来自特定实验条件，不必逐峰一致。

### 密度或化学式不对

- 检查 CIF 是否只给了非对称单元；
- 检查空间群与原点选择；
- 检查占有率是否小于 1；
- 检查晶胞参数单位是否为 Å。

## 数据与工程

### 刷新后数据丢了

本版本不做自动持久化。请使用 **保存工程**，或导出 `.xy` 与配方。

### 工程文件很大

它包含完整原始数据。十万点约几 MB；可以只用 `.xy` + 配方，或先裁剪/抽稀再保存。

### 能离线使用吗？

可以。构建产物不依赖 CDN；首次加载后，浏览器缓存即可离线打开（示例 DIF 需要文件随站点部署）。

### 为什么没有 3D 晶胞查看？

v0.1 聚焦数据处理、倒易空间与衍射模拟；3D 查看计划在 v1.1 加入。当前的晶体结构页提供原子表、密度与低角反射预览。

## 浏览器与性能

### 支持哪些浏览器？

Chrome / Edge / Firefox 的较新版本。Safari 16+ 理论可用，但未做充分测试；不建议使用 IE。

### 十万点很卡

- 图表做了按像素抽稀，但步骤重算仍会遍历全部点；
- 建议先裁剪/抽稀再处理；
- 关闭其他标签页，避免内存压力。
