# 不同波长数据的对比

目标：把 Cu 靶、同步辐射、电子衍射的数据放到同一个横坐标上比较。

## 为什么不能直接比 2θ

布拉格公式：

$$
2d\sin\theta=\lambda
$$

同一个 d，波长不同，2θ 不同。直接把不同波长的 2θ 画在一起，峰会错位。

## 换成 1/d

$$
\frac{1}{d}=\frac{2\sin\theta}{\lambda}
$$

`1/d` 只与晶面间距有关，与波长无关。不同波长的同一反射在 `1/d` 轴上应对齐。

| 辐射 | λ (Å) | 典型 2θ 范围 |
|---|---|---|
| Cu Kα1 | 1.54056 | 5–120° |
| Co Kα1 | 1.78897 | 5–120° |
| Mo Kα1 | 0.70930 | 5–60° |
| Ag Kα1 | 0.55941 | 5–50° |
| 同步辐射 | 0.4–1.0 | 依实验站 |
| 200 kV 电子 | 0.02508 | 不适用（用 g） |

## 在工具中操作

### XRD/DIF 数据

1. 打开 **DIF → XY**；
2. 横坐标选择 **1/d（Å⁻¹）**；
3. 导出 CSV；
4. 在 Origin 中把不同波长的数据画在同一 X 轴。

注意：1/d 转换使用 DIF 参数行中的波长。若波长缺失，会报错。

### 电子衍射

SAED 的 `g = 1/d`，直接与 XRD 的 `1/d` 对比：

- SAED 页的 `|g|` 单位是 Å⁻¹；
- 与 XRD 的 `1/d` 数值可直接比较；
- 电子衍射的 `g` 范围通常更大（0–2 Å⁻¹）。

## 实操：Cu vs 同步辐射

1. 分别导入两份数据；
2. 各自做 Jade 映射/配方（如果要做 Jade）；
3. 在 DIF 页分别导出 1/d；
4. 在 Origin 中叠加；
5. 用同一组 PDF 卡片验证峰位。

::: warning 1/d 不是 Q
有些文献用 `Q = 4π sinθ/λ`。本工具使用晶体学约定 `1/d = 2 sinθ/λ`，不含 2π。比较时注意单位。
:::

## 常见问题

**峰位仍不对齐**

- 波长输入错误；
- 仪器零点偏移；
- 样品高度/透明效应；
- 固溶导致晶格参数变化（不是波长问题）。

**低角数据缺失**

- 短波长下低角反射可能超出探测器范围；
- 长波长下高角反射可能不可见；
- 选择靶材时要兼顾 d 范围与分辨率。

**1/d 轴上的峰宽**

- 峰宽随 2θ 变化，转换到 1/d 后不再等宽；
- 做定量比较时应在 2θ 空间拟合，再转换峰位。
