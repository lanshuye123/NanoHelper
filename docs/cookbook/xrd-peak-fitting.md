# XRD 峰拟合与背底

目标：把一段 XRD 数据送进 Jade，完成扣背底、寻峰与拟合，并导出 DIF 供本工具转换。

## 准备

- 两列 XRD 数据（2θ + 强度），或使用工具中的示例；
- Jade（本流程以 Jade 6.x 的界面为例）；
- 已知靶材与波长。

## 步骤 1：检查与裁剪

1. 在 **导入与预处理** 中导入；
2. 检查 X 是否在 0–140、Y 是否全为正；
3. 低角空气散射/高角噪声可先裁剪；
4. 若需要，做 Kα2 剥离（见 [Kα2 剥离](/docs/cookbook/kalpha2)）。

::: tip 拟合前是否要平滑
Jade 的拟合对噪声有一定容忍。轻度平滑可以稳定初值，但会改变峰宽；如果后续要做 Scherrer，建议不平滑或使用相同流程处理标样。
:::

## 步骤 2：导入 Jade

1. Jade → `File → Read`；
2. 选择 `.xy`；
3. 确认底部状态栏的 2θ 范围与点数。

## 步骤 3：扣背底

1. 右键 **BE** 图标，打开背底参数；
2. 左侧是自动背底寻找程度，从左到右依次降低；
3. 右侧选择背底拟合函数；
4. 需要扣除 Kα2 时勾选 **Strip K-alpha2**；
5. 若自动背底不理想，在低谷处手动加点；
6. 确认后点击 **Remove**（或应用）。

背底点应落在**真正的低谷**，不要落在峰肩上。强背底或非晶鼓包需要更多手动点。

## 步骤 4：寻峰与拟合

1. 右键 **Fit** 图标，打开拟合选项；
2. 勾选 **Paint Individuals**（每个峰单独绘制）；
3. 左键 Fit，进入手动寻峰；
4. 在每个峰顶附近点一下，Jade 会建立一个峰；
5. 拟合完成后检查残差与峰参数（2θ、FWHM、面积、高度）。

拟合参数的经验：

- 强峰、孤立峰：先拟合；
- 重叠峰：限制峰位/峰宽范围，避免峰“跑掉”；
- 非晶鼓包：不要强行拟合成布拉格峰；
- 背底与峰同时拟合时，注意背底不要“吃掉”峰尾。

## 步骤 5：导出 DIF

`File → Save → DIF`，得到类似：

```text
10/20/26 10:16  FIT Red Paint Pigment Mixture
 20  0.02  4 Cu 1.54056  78  2901 (Raw Pattern)
 ...
 20  0.02  4 Cu 1.54056  78  2901 (Background)
 ...
 23.18  0.02  4 Cu 1.54056  29.12  298 (Fitted Profile 1)
 ...
 20  0.02  4 Cu 1.54056  78  2901 (Overall Profile)
```

## 步骤 6：DIF → XY

1. 打开 **DIF → XY**；
2. 拖入 `.dif`；
3. 检查六个块是否都被识别；
4. 选择 Origin 宽表；
5. 导出 CSV。

若之前做过坐标映射，加载 `recipe.json` 反算。

## 步骤 7：质量检查

- `Rp` 是否可接受？（本工具给出无权重 Rp）
- Diff 曲线是否只在噪声级别波动？
- 峰位是否与 PDF 卡片一致？
- 峰宽是否随 2θ 合理变化？

## 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 拟合峰数量过多 | 把噪声当峰 | 提高阈值/减少手动点 |
| 峰位偏移 | 零点误差、样品高度 | 用标样做角度校正 |
| 峰宽异常大 | 晶粒细、应变、仪器展宽 | 做 Scherrer/W–H，扣仪器展宽 |
| 背底为负 | 背底点过高 | 降低背底或改用手动点 |
| DIF 块缺失 | Jade 未保存全部曲线 | 在 Jade 导出选项中勾选全部曲线 |
