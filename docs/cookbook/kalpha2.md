# Kα2 剥离

目标：去掉 Kα2 卫星峰，让峰位与峰形更接近单色 Kα1，便于峰拟合与 Scherrer 分析。

## 为什么有 Kα2

X 射线管产生 Kα1 与 Kα2 两条谱线：

| 靶 | Kα1 (Å) | Kα2 (Å) | 强度比 |
|---|---|---|---|
| Cu | 1.54056 | 1.54439 | ~0.5 |
| Co | 1.78897 | 1.79285 | ~0.5 |
| Mo | 0.70930 | 0.71359 | ~0.5 |

同一 d 下，Kα2 的布拉格角更大：

$$
\sin\theta_2=\frac{\lambda_2}{\lambda_1}\sin\theta_1
$$

因此每个峰右侧会有一个较弱的卫星峰。低角时重叠严重，高角时分离更明显。

## Rachinger 方法

对角度 `x`：

$$
I_1(x)=I_{\text{obs}}(x)-r\,I_1(x')
$$

其中：

- `r = I(Kα2)/I(Kα1)`，默认 0.5；
- `x'` 是同一 d 对应的 Kα1 角度（`x' < x`）；
- `I_1(x')` 取已修正曲线的插值。

实现按角度从低到高扫描，因此 `x'` 处已经修正。

## 在工具中操作

1. 打开 **导入与预处理**；
2. 添加 **Kα2 剥离**；
3. 确认 Kα1/Kα2 波长（默认 Cu）；
4. 强度比 0.5；
5. 观察峰形：Kα2 卫星峰应基本消失，主峰不应明显变窄或出现负值。

::: tip 先扣背底
Kα2 剥离假设背景已经扣除或至少平缓。强背底会让 `r` 的估计偏差，建议先做 SNIP/锚点背底。
:::

## 参数检查

- 若剥离后出现负值：强度比可能过大，或数据信噪比太低；
- 若卫星峰仍在：确认使用的是 Kα1/Kα2 而不是 Kβ；
- 若主峰变窄很多：可能剥离过度，减小 `r`；
- 若峰位移动：正常，剥离后峰位应更接近 Kα1 的真实位置。

## 什么时候不需要剥离

- 只做物相鉴定：不需要；
- 用 Jade 自动寻峰：Jade 可以选择剥离选项；
- Raman/IR/TGA：完全不适用；
- 同步辐射/单色器数据：通常已经是单波长。

## 对 Scherrer 的影响

未剥离时，Kα2 会使峰宽被高估，D 被低估。若做尺寸分析：

1. 对样品和标样使用**相同**的 Kα2 处理；
2. 或直接使用单色 Kα1 数据；
3. 记录是否剥离，便于复现。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 峰变成双峰 | 只处理了部分角度 | 检查数据范围与步长 |
| 峰高下降 | 正常，Kα2 被移除 | 不要重新归一化 |
| 负值 | r 过大/噪声 | 减小 r 或先平滑 |
| 峰位不变 | 可能没有真正应用步骤 | 检查步骤是否启用 |
