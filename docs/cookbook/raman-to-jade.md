# Raman → Jade → Origin 全流程

目标：把一段 Raman 光谱送进 Jade 做分峰，拟合后把峰位/峰宽/面积还原回 cm⁻¹，并在 Origin 中画图。

## 准备

- 一段两列 Raman 数据（位移 cm⁻¹ + 强度）；
- 或直接使用示例 **Raman · 锐钛矿**；
- 本工具、Jade、Origin。

示例包含 144、197、399、513、639 cm⁻¹ 五个峰，X 范围 100–2000 cm⁻¹。

## 步骤 1：导入

1. 打开 **数据处理 → 导入与预处理**；
2. 拖入文件，或点击示例 **Raman · 锐钛矿**；
3. 确认曲线与统计：3801 点，X 100–2000，Y 约 133–1076。

此时「Jade 兼容性」会报 X 超出 0–140，这是预期的。

## 步骤 2：预处理（可选）

Raman 数据通常只需轻度处理：

1. **平滑**：Savitzky–Golay，窗口 11，阶数 3（不要过度）；
2. **扣背底**：SNIP，迭代 30–60；若荧光背底很强，用锚点线性/多项式；
3. **归一化**：最大值归一（可选，便于叠图）。

::: tip 不要先归一化再扣背底
归一化会把背底一起缩放，影响背底判断。先扣背底，最后归一化。
:::

## 步骤 3：Jade 坐标映射

添加 **Jade 坐标映射**，模式选 **非衍射数据：X→[0,100]**。

页面会显示类似：

$$
x' = 0.0526316\,x - 5.26316
$$

$$
y' = 10.6087\,y - 1429.76
$$

以及映射后范围：

```text
X: 0.000 → 100.000
Y: 0.500 → 10000.0
```

此时五个峰在 Jade 坐标中的位置约为：

| 原始 (cm⁻¹) | 映射后 X |
|---|---|
| 144 | 2.32 |
| 197 | 5.11 |
| 399 | 15.74 |
| 513 | 21.74 |
| 639 | 28.37 |

**记住这些数字**：在 Jade 里看到的峰位就是它们。

## 步骤 4：导出

打开 **数据处理 → Jade 导出**：

1. 确认兼容性全部通过；
2. X 小数位 6，Y 小数位 4，CRLF；
3. 点击 **导出 .xy**；
4. 点击 **配方 JSON**，保存 `*.recipe.json`。

把 `.xy` 和配方放在同一个文件夹，文件名最好对应。

## 步骤 5：在 Jade 中拟合

1. Jade → **File → Read**，选择 `.xy`；
2. 右键 **BE** 图标设置背底参数，在低谷处手动加背底点；
3. 右键 **Fit**，勾选 **Paint Individuals**；
4. 左键 Fit，手动点击每个峰；
5. 拟合完成后，**File → Save → DIF**。

::: warning 不要在 Jade 里改坐标
拟合期间不要再做 X 平移/归一化；否则配方反算会多一层未知变换。
:::

## 步骤 6：DIF → Origin

1. 打开 **数据处理 → DIF → XY**；
2. 拖入 `.dif`，确认识别出 Raw / Background / Fitted Profile / Overall；
3. 在「配方反算」中加载第 4 步的 `recipe.json`；
4. 输出形态选 **Origin 宽表**，CSV；
5. 导出。

此时 X 已反算回 cm⁻¹，各列：

```text
X, Raw, Background, Overall, Diff, Fit1, Fit2, …
```

## 步骤 7：在 Origin 中画图

1. `File → Import → CSV`；
2. 把 X 列设为 X；
3. 选中 Raw、Overall、Fit1… → `Plot → Line+Symbol`；
4. Diff 列单独画，或用 `B-D` 做真实差值；
5. 调整图例、坐标轴、字体。

## 检查清单

- [ ] Jade 中五个峰的位置与上表一致；
- [ ] 拟合峰的个数与肉眼看到的峰一致；
- [ ] 反算后的峰位与原始 Raman 峰位相差 < 0.1 cm⁻¹；
- [ ] Diff 曲线在峰位处没有明显系统偏差；
- [ ] 导出的 CSV 没有 NaN（除非有意保留区间外数据）。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| Jade 中峰位是 0–100 | 正常，已映射 | 用配方反算 |
| 反算后峰位差很多 | 配方不是这份数据的 | 重新生成配方 |
| 峰宽变宽 | 平滑过度或 Kα2 误用 | 减小窗口；Raman 不需要 Kα2 |
| Y 出现负值 | 扣背底过度 | 减小 SNIP 迭代或关闭负值截断 |
