# Rietveld 图与差值曲线

目标：画一张标准的 Rietveld 风格图：实验点、计算线、差值线，以及可选的 Bragg 位置刻度。

## 数据来源

| 列 | 来源 | 说明 |
|---|---|---|
| 实验 | XRD 原始数据 | 点或线 |
| 计算 | Rietveld 软件输出 | 通常是连续曲线 |
| 差值 | 实验 − 计算 | 放大 2–5 倍显示 |
| Bragg | 软件输出的峰位表 | 竖线刻度 |

本工具的 DIF → XY 可以提供前三列（Raw、Overall、Diff），但 **DIF 通常不含 Bragg 位置表**。Bragg 位置需要从 Rietveld 软件（FullProf/GSAS/Topas）单独导出，或在 Jade 的峰表里复制 2θ。

## 导出

1. DIF → XY；
2. 宽表；
3. 加载配方（如有映射）；
4. 导出 CSV。

如果使用 FullProf/GSAS，直接导出其 `.dat`/`.csv` 三列（2θ, obs, calc），本工具不是必需的。

## Origin 设置

### 1. 导入与列角色

- A(X)：2θ
- B(Y)：实验
- C(Y)：计算
- D(Y)：差值

### 2. 绘图

1. 选中 B、C → `Plot → Line+Symbol`；
2. 实验：Symbol only（size 2–3），计算：Line only（宽度 1.2）；
3. 添加 D 列：Plot → Line，设为 Y offset 或独立轴。

课程笔记中的关键操作：

- 双击图层 → `Independent` 模式，关闭组合，分别编辑；
- 差值线用 `B-D` 或 `C-B` 得到真实差值；
- 若使用 offset 模式，记得在函数中改回 `B-D`。

### 3. 差值线

- 位置：主图下方 10–20% 高度；
- Y 轴范围约为实验强度的 ±5–10%；
- 零线用虚线；
- 差值线放大 2–5 倍时要在图注中说明。

### 4. Bragg 位置

1. 导入 Bragg 表（2θ, phase）；
2. 每个相一行，或用不同颜色；
3. `Plot → Column` 或 `Drop Lines`；
4. 放在主图与差值线之间；
5. 高度约为图高的 3–5%。

### 5. 多相

- 每个相的 Bragg 位置单独一层；
- 用颜色/符号区分；
- 图例标注相名与 PDF 编号。

## 版式建议

```text
主图：height 55–60%
Bragg：height 5%
差值：height 15–20%
```

- 主图与差值图共用 X 轴；
- 只保留最下方的 X 轴刻度；
- 主图不显示 X 轴标签，差值图显示；
- 图例放在主图右上角空白处。

## 检查清单

- [ ] 实验与计算同尺度；
- [ ] 差值线零线清晰；
- [ ] 差值没有整体倾斜（否则背底/尺度不一致）；
- [ ] Bragg 位置与峰位对齐；
- [ ] 图注写明 Rp/Rwp、λ、相组成。

## 常见问题

**差值整体倾斜**

- 实验与计算的背底处理不同；
- 归一化因子不一致；
- 检查 Overall 是否包含背底。

**Bragg 位置与峰位错位**

- 2θ 零点偏移；
- 波长不同；
- 卡片/软件使用的 2θ 定义不同（θ vs 2θ）。

**实验点太密**

- 抽稀到 0.01–0.02° 再画；
- 或只画每隔 N 个点。
