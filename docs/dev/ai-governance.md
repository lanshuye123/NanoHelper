# 界面文案与工具状态治理

本页面向开发者与 AI 协作代理，规定最终界面的文案边界，以及工具自动保存/重置的开发约束。**文档可以技术化，界面不可以。**

## 为什么

CrystalToolBox 的使用者是材料、物理、化学等方向的课程学生与科研人员。他们关心的是样品、谱图、晶胞、粒径与结论，而不是软件如何实现。界面里出现实现细节、部署路径、调试说明或“本地运行”“数据不上传”一类技术卖点，会把用户的注意力从科学问题引开。

## 强制规则

最终界面（`src/views/`、`src/components/`、导航、状态栏、首页、关于页、按钮、提示、空状态、错误信息、工具提示、`aria-label`）不得出现：

1. **实现与部署术语**：iframe、同源、静态构建、构建产物、`public/...`、hash 路由、Canvas、Vue、Vite、Pinia、TypeScript、KaTeX、spglib、pyxtal、localStorage、DOM、API、CDN、bundle、组件、渲染、部署、路径、文件系统、服务器、浏览器本地解析、画布、剪贴板等。
2. **技术卖点**：本地运行、数据不上传、不会上传、数据不离开电脑、纯前端、无后端、无账号、浏览器本地计算、离线可用、100% 本地、无需安装、静态站点等。
3. **调试/实现说明**：为什么这样实现、数据放在哪个目录、如何构建、如何嵌入、如何部署、兼容性兜底、内部模块名称、开发者才知道的错误原因。
4. **开发者解释**：架构、依赖、性能、缓存、路由、状态管理、打包、测试等。

允许：

- 领域语言：XRD、SAED、晶胞、晶面、晶带、标尺、粒径、空间群、Wyckoff、衬度传递函数、相机常数；
- 操作步骤、单位、误差、适用范围、结果解释、导出建议；
- 科学方法名、文件格式名（CIF、XY、DIF 等）；
- 用户能执行的排查建议，例如“图片无法打开，请转换为 PNG 或 JPEG”。

## 写法对照

| ------------------------------------------------------------------------------------ | ---------------------------------------------------------- |

## 工具状态与重置（强制）

每个有输入的工具页都必须自动保存，并提供「恢复默认」与「清空本页」。具体实现约定：

1. 表单参数用 `src/composables/useToolDraft.ts`；谱图、DIF、图像、测量记录等大对象用 `src/composables/useToolRecord.ts`。
2. 键名由 `src/utils/persist.ts` 统一生成，`toolId` 与 `src/tools/registry.ts` 一致；不得在页面里手写存储键。
3. 恢复必须在 watcher 启动前完成；旧版本、损坏数据、类型不符时回退默认值，不得抛错。
4. “恢复默认”只重置本页输入，保留数据和共享结构；“清空本页”清除输入、结果与记录，涉及自有数据的页面同时清除数据，并先确认。
5. 普通页面清空不得重置共享晶体结构；共享结构只由「晶体结构」页管理，并提示其他页面会同步变化。
6. 只读页面可以隐藏这两个按钮，但必须提供等价的复位动作。
7. 界面只说“自动保存 / 已恢复上次输入 / 恢复默认 / 清空本页 / 本页记录”，不得出现 `localStorage`、`IndexedDB`、缓存、持久化、存储层、序列化、schema、防抖、watcher 等实现词。
8. 保存失败必须给出用户可执行的提示，不得静默失败；失败不能阻塞计算与导出。
9. 不保存撤销历史、弹窗开合、忙碌状态、错误文本、临时选中行、文件句柄或密钥。
10. 新增工具时，自动保存、恢复默认、清空本页、文档与测试必须与工具功能同批交付。

详细开发步骤见[新增一个工具](./adding-a-tool.md)；验收命令与检查项见 `AGENTS.md`。

## 验收

自动化：`tests/ui-copy.spec.ts` 扫描禁用短语；`tests/tool-state-coverage.spec.ts` 检查每个交互工具页是否接入自动保存、恢复默认与清空本页；`tests/toolDraft.spec.ts` 覆盖恢复与清空行为。三者必须保持通过。

人工：

1. 全量搜索 `src/views`、`src/components`、`src/config/navigation.ts`；
2. 逐条检查按钮、提示、错误、空状态、`aria-label`；
3. 不把技术说明从界面删掉后又塞进 tooltip；
4. 技术细节留在 `README.md`、`docs/`、`AGENTS.md` 与代码注释。
