# 版本记录

## v0.2.0 — 2026-10-24

新增「显微分析」模块与晶体几何工具，并把 CrystalViewer 作为三维晶胞查看器嵌入本站。

### 显微分析

- 颗粒尺寸测量（类 NanoMeasure）：图像导入、标尺标定、逐颗 Feret 测量、阈值 + 连通域自动识别、面积/圆度过滤、平均/标准差/D10/D50/D90/Span/CV、直方图与 Gaussian/Log-normal 拟合；
- 全屏测量工作区：标定后一键放大图像，保留画线、缩放、撤销与清空；
- 导出测量 CSV、分组 CSV、NanoMeasure 风格 TXT、标注 PNG、分布 PNG 与工程 JSON；
- SAED 指标化：由两个 R（或 d）与夹角反算 d，枚举 (hkl)₁/(hkl)₂ 与带轴，支持 d/角度容差、空间群消光检查与候选叠加图；
- 电镜参数计算：相对论电子波长、瑞利分辨率、景深、时间相干长度、球差/色差/像散弥散、磁透镜焦距、电子枪亮度、相机常数与 CTF/Scherzer 离焦。

### 晶体几何

- 晶胞与密度：体积、理论密度、Z 值、化学式量、APF、由密度反算 Z、低角反射；
- 晶面与晶向：Miller/四指数换算、d、晶面/晶向夹角、Weiss 定律、晶带、平面截距与系统消光；
- 晶格参数精修：峰位最小二乘（Levenberg–Marquardt）、仪器零点、参数标准误差、Nelson–Riley 外推；
- 三维晶胞查看器：同源嵌入 CrystalViewer（crystal.jamaccao.cn），支持空间群查询、3D 晶胞、Wyckoff 位置与显示设置。

### 站点

- 新增「显微分析」模块与 `--module-micro` 主题色；
- 顶栏模块分页扩展为：首页 / 数据处理 / 衍射模拟 / 晶体几何 / 显微分析 / 文档中心 / 关于；
- 首页统计更新为 14 个工具页面、4 个计算模块；
- 侧栏配置卡片不再被 flex 压缩，长面板可滚动；
- 关闭态结果抽屉不再在底部露出；
- 新增 7 篇用户指南与公式/术语/工具总览更新；
- 界面文案治理：移除实现/部署说明与技术卖点，新增 `AGENTS.md`、界面文案规范与自动检查；
- 颗粒尺寸测量新增全屏工作区，标定后可一键放大图像。

### 已知限制

- 颗粒自动识别不做分水岭，粘连颗粒会合并；
- SAED 指标化只用两个斑点，存在 180° 不确定性；
- 三维晶胞为内嵌应用，状态不与主站互通；
- 晶格精修只做峰位，不替代 Rietveld。

## v0.1.0 — 2026-10-23

首个可用版本。

### 数据处理

- 通用文本/CSV/TSV/XY/DAT/ASC 导入，自动分隔符与表头嗅探；
- UTF-8 / GBK 编码回退；
- 多列文件列映射；
- Jade DIF 导入（Raw 曲线）；
- PANalytical XRDML 解析；
- 步骤账本：裁剪、重采样、滑动平均、Savitzky–Golay、SNIP/锚点背底、Rachinger Kα2、归一化、Jade 映射、自定义仿射；
- 可逆映射与逆变换；
- Jade 兼容性检查（X 范围、Y 正性、单调、NaN、步长、点数）；
- `.xy` 导出（CRLF、小数位可调）；
- `recipe.json` 导出；
- `.xtalbox.json` 工程保存/打开。

### DIF → XY

- 多块 DIF 解析（Raw/Background/Fitted Profile/Overall）；
- 不同范围块插值到公共网格；
- Origin 宽表/堆叠/仅差值/单曲线；
- CSV 与空白分隔；
- 2θ → 1/d；
- 无权重 Rp；
- 配方反算。

### 晶体学

- 晶格/倒易/体积/倒易参数；
- d 值、晶面/晶向夹角、晶面-晶向夹角；
- 晶带轴、带内晶面、点阵消光；
- 二维倒易面（整数零空间 + Gauss 约化）；
- 结构因子、Waasmaier–Kirfel 散射因子、Friedel 对；
- CIF 解析、对称展开、密度/化学式；
- 带轴 SAED 模拟、相机常数标定、CSV/PNG；
- XRD 理论谱、多重度/LP、Kα2、峰表、Scherrer、Williamson–Hall；
- 15 个预设结构。

### 站点

- BoMIND 风格的顶栏 + 模块侧栏 + 内容面板布局；
- 浅蓝—白默认主题与深色主题；
- 顶栏模块分页：首页 / 数据处理 / 衍射模拟 / 晶体几何 / 文档中心 / 关于；
- 侧栏按模块列出页面，支持收起为图标栏；文档中心在侧栏内分组并支持搜索；
- 全局快速搜索（`Ctrl / ⌘ + K`）；
- 深浅色主题；
- 自研 Canvas 曲线与衍射图；
- 文档中心：用户指南、实战手册、功能说明、开发文档；
- KaTeX 公式、站内搜索、目录、上下篇；
- 移动端响应式；
- 纯静态构建，无后端。

### 已知限制

- 无 3D 晶胞视图；
- 不做 Rietveld/结构解析；
- 不解析二进制厂商格式（`.brml`、`.raw`、`.mdi`）；
- 不做自动持久化/最近工程；
- SAED 为运动学近似，无 HOLZ/动力学；
- XRD 不含吸收、择优取向与仪器几何；
- CIF 只支持常见子集，不做完整语法校验；
- 工程文件不含晶体结构。
