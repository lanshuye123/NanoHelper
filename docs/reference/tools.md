# 工具总览

| 工具 | 路由 | 输入 | 输出 |
|---|---|---|---|
| 导入与预处理 | `/data/import` | 文本/CSV/XY/DIF/XRDML、粘贴、示例 | 处理后曲线、检查报告、工程 |
| Jade 导出 | `/data/jade` | 当前处理结果 | `.xy`、`recipe.json` |
| DIF → XY | `/data/dif` | `.dif`、可选配方 | CSV/XY 多列、Rp |
| 倒易空间 | `/crystal/reciprocal` | 晶格参数 | d 值、夹角、带轴、二维倒易面 |
| 电子衍射模拟 | `/crystal/saed` | 结构 + 带轴 + 电压/相机长度 | 斑点图、指数、CSV/PNG |
| XRD 模拟与分析 | `/crystal/xrd` | 结构 + 波长/范围/峰型 | 理论谱、峰表、Scherrer/W–H |
| 晶体结构 | `/crystal/structure` | CIF / 预设 | 完整晶胞、密度、低角反射 |

---

## 导入与预处理

**输入**

- 两列或多列文本：CSV、TSV、TXT、XY、DAT、ASC；
- Jade DIF（取 Raw 曲线）；
- PANalytical XRDML；
- 剪贴板文本；
- 内置示例。

**参数**

- 列映射（X/Y）；
- 步骤链：裁剪、重采样、平滑、扣背底、Kα2、归一化、Jade 映射、自定义仿射。

**输出**

- 当前处理后曲线（可导出工程）；
- Jade 兼容性问题列表；
- 步骤账本。

**限制**

- 不解析二进制厂商格式；
- 不做自动持久化；
- 不做峰拟合（交给 Jade）。

---

## Jade 导出

**输入**：当前处理结果 + 已启用的 `jade-map` 步骤。

**参数**

- X/Y 小数位（默认 6/4）；
- CRLF/LF；
- 注释表头开关；
- 文件名。

**输出**

- 两列 `.xy`；
- `recipe.json`（含仿射系数、步骤、校验和）。

**限制**

- 存在错误时禁止导出；
- 需要先添加 `jade-map` 步骤；
- 不生成 Jade 工程文件。

---

## DIF → XY

**输入**：Jade `.dif`，可选 `recipe.json`。

**参数**

- 块选择；
- 输出形态：宽表/堆叠/仅差值/单曲线；
- 横坐标：2θ / 1/d；
- 区间外：0 / NaN；
- CSV/空白；
- 小数位与表头。

**输出**

- CSV/XY；
- Rp（Raw vs Overall）；
- 导出预览。

**限制**

- DIF 需包含参数行；
- 不生成 Bragg 位置表；
- 拟合峰块区间外为 0/NaN，不是真实测量值。

---

## 倒易空间

**输入**：a, b, c, α, β, γ；最大指数；点阵类型；带轴；显示半径。

**输出**

- 体积、a\*b\*c\*、α\*β\*γ\*；
- d 值表；
- 晶面/晶向夹角；
- 晶带轴与带内晶面；
- 二维倒易面基矢与斑点。

**限制**

- 只处理点阵消光；完整消光由结构因子处理；
- 不画 3D 倒易空间；
- 不含仪器零点。

---

## 电子衍射模拟

**输入**：结构、带轴、电压、相机长度、最大 |g|、斑点大小模式。

**输出**

- 斑点图（PNG）；
- 斑点表（hkl、d、|g|、I、R）；
- 二维基矢；
- 相机常数标定。

**限制**

- 运动学近似；
- 无 HOLZ、动力学效应、样品厚度；
- 无探测器响应/吸收。

---

## XRD 模拟与分析

**输入**：结构、波长、2θ 范围/步长、峰型/FWHM/η、Kα2、背底、零点、归一化强度。

**输出**

- 理论谱（可导出 Jade XY）；
- 峰表（hkl、d、2θ、多重度、|F|²、I）；
- Scherrer 尺寸；
- W–H 尺寸/应变/R²；
- 与实验数据叠加。

**限制**

- 运动学、无择优取向/吸收；
- 不做 Rietveld；
- 峰型按高度归一化，不是仪器函数。

---

## 晶体结构

**输入**：CIF 或预设。

**输出**

- 完整晶胞原子表；
- 晶胞体积、密度、化学式；
- 低角反射预览；
- 与 SAED/XRD 共享的当前结构。

**限制**

- 只有各向同性 B；
- 无 3D 视图；
- 不处理无序/超胞/磁结构；
- 不导出 CIF。
