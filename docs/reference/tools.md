# 工具总览

| 工具           | 路由                  | 输入                              | 输出                            |
| -------------- | --------------------- | --------------------------------- | ------------------------------- |
| 导入与预处理   | `/data/import`        | 文本/CSV/XY/DIF/XRDML、粘贴、示例 | 处理后曲线、检查报告、工程      |
| Jade 导出      | `/data/jade`          | 当前处理结果                      | `.xy`、`recipe.json`            |
| DIF → XY       | `/data/dif`           | `.dif`、可选配方                  | CSV/XY 多列、Rp                 |
| 倒易空间       | `/crystal/reciprocal` | 晶格参数                          | d 值、夹角、带轴、二维倒易面    |
| 电子衍射模拟   | `/crystal/saed`       | 结构 + 带轴 + 电压/相机长度       | 斑点图、指数、CSV/PNG           |
| XRD 模拟与分析 | `/crystal/xrd`        | 结构 + 波长/范围/峰型             | 理论谱、峰表、Scherrer/W–H      |
| 晶体结构       | `/crystal/structure`  | CIF / 预设                        | 完整晶胞、密度、低角反射        |
| 晶胞与密度     | `/crystal/cell`       | 晶胞参数 + 化学式 / 当前结构      | 体积、密度、Z、APF、低角反射    |
| 晶面与晶向     | `/crystal/indices`    | 晶胞 + (hkl)/[uvw] + 空间群       | d、夹角、晶带、四指数、消光     |
| 晶格参数精修   | `/crystal/refine`     | 峰位 (2θ,hkl) + 波长              | 精修晶胞、零点、NR 外推、残差   |
| 三维晶胞查看器 | `/crystal/viewer`     | 空间群编号/符号                   | 内嵌 CrystalViewer 3D 晶胞      |
| 颗粒尺寸测量   | `/micro/particles`    | SEM/TEM 图像                      | 粒径表、分布、拟合、CSV/TXT/PNG |
| SAED 指标化    | `/micro/saed-index`   | R/d + 夹角 + 晶胞                 | hkl、带轴、候选表、叠加图       |
| 电镜参数计算   | `/micro/tem`          | 电压、半角、像差、相机长度        | λ、δ、像差、焦距、Lλ            |

---

## 导入与预处理

**输入**

- 两列或多列文本：CSV、TSV、TXT、XY、DAT、ASC；
- Jade DIF（取 Raw 曲线）；
- PANalytical XRDML；
- 剪贴板文本；
- 内置示例。

**参数**

- 列映射（X/Y）；
- 步骤链：裁剪、重采样、平滑、扣背底、Kα2、归一化、Jade 映射、自定义仿射。

**输出**

- 当前处理后曲线（可导出工程）；
- Jade 兼容性问题列表；
- 步骤账本。

**限制**

- 不解析二进制厂商格式；
- 不做自动持久化；
- 不做峰拟合（交给 Jade）。

---

## Jade 导出

**输入**：当前处理结果 + 已启用的 `jade-map` 步骤。

**参数**

- X/Y 小数位（默认 6/4）；
- CRLF/LF；
- 注释表头开关；
- 文件名。

**输出**

- 两列 `.xy`；
- `recipe.json`（含仿射系数、步骤、校验和）。

**限制**

- 存在错误时禁止导出；
- 需要先添加 `jade-map` 步骤；
- 不生成 Jade 工程文件。

---

## DIF → XY

**输入**：Jade `.dif`，可选 `recipe.json`。

**参数**

- 块选择；
- 输出形态：宽表/堆叠/仅差值/单曲线；
- 横坐标：2θ / 1/d；
- 区间外：0 / NaN；
- CSV/空白；
- 小数位与表头。

**输出**

- CSV/XY；
- Rp（Raw vs Overall）；
- 导出预览。

**限制**

- DIF 需包含参数行；
- 不生成 Bragg 位置表；
- 拟合峰块区间外为 0/NaN，不是真实测量值。

---

## 倒易空间

**输入**：a, b, c, α, β, γ；最大指数；点阵类型；带轴；显示半径。

**输出**

- 体积、a\*b\*c\*、α\*β\*γ\*；
- d 值表；
- 晶面/晶向夹角；
- 晶带轴与带内晶面；
- 二维倒易面基矢与斑点。

**限制**

- 只处理点阵消光；完整消光由结构因子处理；
- 不画 3D 倒易空间；
- 不含仪器零点。

---

## 电子衍射模拟

**输入**：结构、带轴、电压、相机长度、最大 |g|、斑点大小模式。

**输出**

- 斑点图（PNG）；
- 斑点表（hkl、d、|g|、I、R）；
- 二维基矢；
- 相机常数标定。

**限制**

- 运动学近似；
- 无 HOLZ、动力学效应、样品厚度；
- 无探测器响应/吸收。

---

## XRD 模拟与分析

**输入**：结构、波长、2θ 范围/步长、峰型/FWHM/η、Kα2、背底、零点、归一化强度。

**输出**

- 理论谱（可导出 Jade XY）；
- 峰表（hkl、d、2θ、多重度、|F|²、I）；
- Scherrer 尺寸；
- W–H 尺寸/应变/R²；
- 与实验数据叠加。

**限制**

- 运动学、无择优取向/吸收；
- 不做 Rietveld；
- 峰型按高度归一化，不是仪器函数。

---

## 晶体结构

**输入**：CIF 或预设。

**输出**

- 完整晶胞原子表；
- 晶胞体积、密度、化学式；
- 低角反射预览；
- 与 SAED/XRD 共享的当前结构。

**限制**

- 只有各向同性 B；
- 结构页自身不画 3D；3D 请用三维晶胞查看器；
- 不处理无序/超胞/磁结构；
- 不导出 CIF。

---

## 晶胞与密度

**输入**：当前结构（预设/CIF）或手动晶胞参数 + 化学式 + Z；堆积模型。

**输出**

- 晶胞体积与倒易参数；
- 化学式单元数 Z、化学式量 M、理论密度；
- 由实测密度反算 Z；
- APF、配位数、原子半径；
- 低角反射（d、2θ Cu Kα1）。

**限制**

- 化学式解析只支持常见整数/小数计量比；
- 理论密度不含缺陷与表面；
- 堆积因子按硬球模型。

---

## 晶面与晶向

**输入**：晶胞、两个晶面、两个晶向、带轴、空间群编号。

**输出**

- d、|g|、2θ；
- 晶面/晶向/晶面-晶向夹角；
- Weiss 定律；
- 四指数换算与平面截距；
- 两晶面决定的带轴与带内允许晶面；
- 空间群系统消光与轴向条件。

**限制**

- 不画 3D 晶面；
- 消光基于空间群数据库设置；
- 带内晶面受最大指数限制。

---

## 晶格参数精修

**输入**：带 hkl 的峰位（2θ）、波长、初始晶胞、精修参数选择。

**输出**

- 精修晶胞与零点；
- 参数标准误差；
- 逐峰残差、RMS、Rwp；
- 立方晶系的 Nelson–Riley 外推。

**限制**

- 只做峰位最小二乘，不做峰形/Rietveld；
- 权重默认 1；
- 不含样品位移、透明效应等系统误差。

---

## 三维晶胞查看器

**输入**：空间群编号或 H-M 符号。

**输出**：3D 晶胞、Wyckoff 位置、原子点位、显示设置。

**限制**：内嵌应用，状态不与主站互通；需要 `public/crystal-viewer/` 构建产物。

---

## 颗粒尺寸测量

**输入**：SEM/TEM 图像（PNG/JPEG/BMP/WebP）、标尺真实长度、测量/识别参数。

**输出**

- 逐颗 Feret 直径或面积等效圆直径；
- 平均值、标准差、D10/D50/D90、Span、CV、偏度/峰度；
- 直方图与 Gaussian / Log-normal 拟合；
- 测量 CSV、分组 CSV、TXT 报告、标注 PNG、分布 PNG、JSON。

**限制**

- 自动识别不做分水岭，粘连颗粒会合并；
- 不做亚像素边缘拟合；
- 不保存图像本身。

---

## SAED 指标化

**输入**：晶胞、空间群、两个 R（或 d）、相机常数、夹角、容差。

**输出**

- 候选 (hkl)₁/(hkl)₂ 与带轴；
- d、夹角、偏差、评分；
- 系统消光检查；
- 候选叠加图与单斑候选表。

**限制**

- 只用两个斑点；
- 运动学近似；
- 不做全自动斑点检测；
- 180° 不确定性需倾转确认。

---

## 电镜参数计算

**输入**：加速电压、收集半角、Cs/Cc、能量展宽、离焦、相机长度、透镜 K/I/N、束流/束斑/发射角。

**输出**

- 电子波长、γ、速度、动量；
- 瑞利分辨率、景深、相干长度；
- CTF 曲线、Scherzer 离焦、第一零与点分辨率；
- 球差/色差/像散弥散；
- 磁透镜焦距与 I·N；
- 相机常数 Lλ 与 d/R 换算；
- 电子枪亮度。

**限制**

- 三阶像差近似；
- 不模拟电子轨迹；CTF 为弱相位近似，不含包络与信息极限；
- 不含空间电荷、样品充电。
